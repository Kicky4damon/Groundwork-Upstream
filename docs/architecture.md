# 개발 구조 및 검증 기록

## 1차 구현 범위

ACadSharp를 교체 가능한 파서 경계로 두고 CLI가 버전이 명시된 JSON을 출력한다.
현재 DB 서버나 웹 서버는 없으며 파일 단위 JSON 저장소다. DB/API 구현은 다음 단계다.
원본 CAD 사실과 사용자 해석은 index/review 파일로 분리한다.
지원하지 않는 객체와 미분할 Model을 명시하며 정확도나 일치율을 임의로 만들지 않는다.

## 공통 데이터 모델의 다음 확장

1. DocumentRevision: 원본 파일 해시, 프로젝트 ID, 도면 버전, 단위.
2. CadEntity: 현재 entity ID/handle과 원본 형상. 수정 불가능한 원본 증거.
3. DrawingPage: 배치 또는 수동/자동 도곽 영역, 좌표계, 분리 근거와 확정 상태.
4. DesignObject: 실제 부재 ID. 여러 CAD 객체의 묶음, 블록 인스턴스 경로, 클래스, 치수 출처.
5. SpecificationRevision: 사용자 규격, 단위, 허용오차, 적용 대상, 작성자·시점.
6. SiteCapture/SiteObject: LiDAR 또는 3DGS 입력, 취득 시점, 좌표계, 관측 품질.
7. Registration: 설계↔현장 변환행렬, 기준점, 잔차 및 검증 상태.
8. ObjectMatch/Measurement: 설계 부재↔현장 객체 연결, 신뢰도, 실측값, 오차, 판정 근거.

CAD entity ID 자체를 프로젝트 수명 전체의 부재 ID로 사용하지 않는다.
review는 초기 입력 계약이다. 복합 부재·수정 이력·revision 간 대응은 DesignObject 계층에서 확장한다.
반복 블록 내부 객체는 root INSERT와 중첩 INSERT 경로로 인스턴스를 구분해야 한다.
원본 레이어 이름은 보존하고 별도의 클래스 사전에 연결한다.

## 다음 구현 순서

1. 대표 현장 DWG 확보 → 도곽/배치/단위/지원 객체 분포 확인.
2. 원본 객체의 2D 미리보기와 수동 도곽 지정, 페이지별 부재 선택.
3. 레이어·블록·문자·형상 규칙 기반 분류 후보와 사용자 수정 UI.
4. SQLite 저장소 및 문서/페이지/설계 부재/규격 API.
5. 한 현장·한 층·한 부재군으로 현장 데이터 좌표 정합과 매칭.
6. 관측 불가와 실제 누락을 구분한 오차 및 적합률 계산.
7. 검증 데이터가 쌓이면 분류 모델과 도곽 자동 탐지 도입.

일치율의 분모와 관측률을 함께 저장하며, 정합 잔차와 시공 오차를 분리한다.
LiDAR와 3DGS는 입력 어댑터를 분리하고 품질이 확인된 측정 정보만 비교에 사용한다.

## 2026-10-23 공개 샘플 검증

ACadSharp 3.8.0 / .NET 10에서 공식 저장소의 공개 샘플을 읽었다.
원본 출처와 commit/SHA256은 validation-sources.json에 기록했다.
원본 바이너리 및 결과는 로컬 artifacts/upstream에 있으며 Git에 포함하지 않는다.

| DWG 버전 | 배치+Model | 레이어 | 객체 정의 | 형상 미지원 객체 |
|---|---:|---:|---:|---:|
| AC1018 | 4 | 21 | 341 | 118 |
| AC1027 | 4 | 19 | 341 | 118 |
| AC1032 | 4 | 19 | 341 | 118 |

이는 읽기 성공 및 구조 추출 검증이다. 같은 계열 샘플의 버전별 파일이며 독립적인 현장 3곳을 검증한 것이 아니다.
파서의 알 수 없는 객체/누락 참조 알림도 결과 warnings에 포함되어 있다.
형상 미지원 118개는 현재 JSON exporter의 지원 범위를 나타내며 파서 전체의 DWG 지원률이 아니다.
현재 상태로 시공 판정 또는 전체 도면 렌더링 정확도를 주장할 수 없다.

## 개발 환경

현재 PC에는 .NET 10 preview SDK와 .NET 10 runtime이 설치되어 있어 net10.0으로 빌드했다.
프로젝트는 preview API를 사용하지 않는다. 다른 개발 PC에서는 .NET 10 SDK로 복원·빌드한다.
개발 대상은 dwg1 브랜치다. 별도 worktree에서 검증한 커밋을 원본 dwg1 checkout에 fast-forward로 반영한다.
